## 🛠️ Tecnologias Utilizadas

Este repositório abrange uma ampla variedade de linguagens de programação, explorando diferentes paradigmas (imperativo, orientado a objetos, funcional e lógico). O foco principal é a construção de soluções robustas entendendo a base de cada linguagem.

**Linguagens aplicadas durante as práticas:**
* 🔵 **C++, C#, Java, Go, Rust**
* 🟡 **JavaScript, Python, Ruby, Lua, Basic**
* 🔴 **Haskell, Lisp, Prolog**
